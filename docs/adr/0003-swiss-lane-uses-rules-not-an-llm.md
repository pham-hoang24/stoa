# Swiss lane answers from DXF geometry, with no LLM

Each Swiss PDF has a DXF sibling with typed layers and polylines, so doors, windows, fixtures and room areas can be read exactly. The lane uses rules fitted on the preview floors instead of a vision model. This gives deterministic answers and evidence boxes, and it is why the gate can run without network access. The cost is that the rules are fitted to the Swiss Dwellings export and will not transfer to other plans.
