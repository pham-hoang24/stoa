# Issue tracker: GitHub

Issues and specifications live in pham-hoang24/stoa on GitHub.
Use the gh CLI.

- Verify the target repository before creating an issue.
- Publish specifications as GitHub issues.
- Read the issue body, labels, and comments when fetching a ticket.
- Use --body-file for multiline issue bodies and comments.
- Follow AGENTS.md for ownership, board coordination, branches, and PRs.
- Use native issue dependencies where available; otherwise record
  “Blocked by: #N” in the issue body.

PRs as a request surface: no.
